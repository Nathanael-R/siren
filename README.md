# Siren

Native, copy-owned components for voice notes, audio waveforms, agent visualizers, and realtime voice interfaces in Expo and React Native.

Siren combines a component registry, the small `@siren-ui/core` runtime, a non-destructive `siren-ui` CLI, an Expo device playground, and web documentation. iOS and Android are supported through the React Native New Architecture; web is experimental.

```sh
pnpm install
pnpm generate
pnpm check
pnpm test
```

See [the product specification](docs/product-spec.md), [contributing guide](CONTRIBUTING.md), and [device matrix](docs/testing/device-matrix.md).
