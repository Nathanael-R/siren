# Introduction

Siren is a component registry for difficult voice, audio, and realtime conversational UI in Expo and React Native. It supplies controlled primitives, Expo convenience hooks, testable controllers, and composed blocks. It is not a voice SDK, transport, transcription system, upload service, or generic UI kit.

Visual source is copied into your application. The small `@siren-ui/core` package provides stable framework-independent types and utilities.
