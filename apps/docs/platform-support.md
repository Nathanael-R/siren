# Platform support

| Platform                      | Status             |
| ----------------------------- | ------------------ |
| iOS 16.4+                     | Supported          |
| Android 7+ / API 24+          | Supported          |
| React Native New Architecture | Required           |
| Expo SDK 57 and 56            | Supported baseline |
| Web                           | Experimental       |

Expo Go can run the bundled SDK packages, but release claims require development/release builds and physical-device verification.
