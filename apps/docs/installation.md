# Installation

```sh
pnpm add @siren-ui/core
pnpm dlx siren-ui init
pnpm dlx siren-ui add waveform
```

For Expo native packages, use `npx expo install` so the installed versions match your SDK. Siren supports SDK 57 and 56, New Architecture only. Review every native-configuration message printed by the CLI; it never edits app config or permission copy silently.
